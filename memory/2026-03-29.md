# 2026-03-29 工作日志

## 话术平台项目

今天帮用户搭建了一个**话术平台**（Speech Script Platform），完整项目路径：
`/root/.openclaw/workspace/话术平台/`

### 技术栈
- 前端：React + Vite + React Router
- 后端：Node.js + Express + sql.js (SQLite)
- 端口：前端 3000，后端 3001

### 主要功能页面
1. **HomePage** (`/home`) - 主页，展示统计、热门话术、公告
2. **Dashboard** (`/dashboard`) - 话术库，浏览话术
3. **PersonalCenter** (`/personal-center`) - 个人中心
4. **UserManagement** (`/user-management`) - 用户管理（管理员）
5. **Announcement** (`/announcement`) - 发布公告页
6. **WebManagement** (`/web-management`) - 网页管理入口
7. **ScriptManagement** (`/script-management`) - 话术管理（编辑/删除/置顶）
8. **AnnouncementManagement** (`/announcement-management`) - 公告管理（发布/过期/恢复/删除/置顶）

### 用户权限系统
- `super_admin` - 超级管理员，可管理所有用户和内容
- `admin` - 管理员，可管理普通用户
- `user` - 普通用户，无管理权限
